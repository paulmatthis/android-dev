# Android Dev

Small Android projects for a Pixel phone, built without Android Studio or Gradle.

| Folder | What it is |
|---|---|
| [`EistWidget/`](EistWidget/) | **Eist Controls**: a 3x1 home screen widget for the Eist reader (cover, play/pause, skip back, skip forward) |
| [`PhoneTransfer/`](PhoneTransfer/) | **Phone Transfer**: a Mac app for copying files between the Mac and an Android phone over USB |
| [`DazzleBright/widget/`](DazzleBright/widget/) | **Dinolite**: a 1x1 widget that toggles a Zengge / Dazzle Bright Bluetooth light |
| [`WordGuess/`](https://github.com/paulmatthis/wordguess) | **Word Guess**: an offline word-guessing game (included here as a git submodule) |

To clone everything, including Word Guess:

```bash
git clone --recurse-submodules https://github.com/paulmatthis/android-dev.git
```
